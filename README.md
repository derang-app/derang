# درنگ

اپ شخصی و آفلاین برای مدیریت کتاب‌ها و بردگیم‌ها؛ وب‌اپ نصب‌شدنی (PWA) با رابط فارسی و راست‌به‌چپ.

## نصب روی گوشی

آدرس اپ: **https://derang-app.github.io/derang/**

1. آدرس اپ را در Chrome اندروید باز کن.
2. از منوی ⋮ گزینهٔ «نصب برنامه» یا «افزودن به صفحهٔ اصلی» را بزن.
3. از این به بعد درنگ مثل یک اپ با آیکن خودش باز می‌شود و بدون اینترنت کار می‌کند.

به‌روزرسانی‌ها خودکارند: نسخهٔ جدید در پس‌زمینه دریافت می‌شود و دفعهٔ بعد که اپ را باز کنی اعمال می‌شود.

## داده‌ها کجا هستند؟

همهٔ کتاب‌ها، بازی‌ها، یادداشت‌ها و عکس‌ها فقط روی همین گوشی، در حافظهٔ مرورگر، ذخیره می‌شوند. هیچ سرور و حساب کاربری‌ای در کار نیست.
اگر «پاک کردن داده‌های سایت» در Chrome را بزنی یا Chrome را حذف کنی، داده‌ها پاک می‌شوند؛ برای همین **مرتب پشتیبان بگیر**.

## پشتیبان‌گیری و بازیابی

- تنظیمات ← پشتیبان‌گیری و بازیابی ← «ساخت و ذخیرهٔ فایل پشتیبان». یک فایل `.drng` ساخته می‌شود که می‌توانی در Drive، تلگرام یا هر جای دیگر نگه داری.
- فایل شامل همهٔ اطلاعات و عکس‌هاست، اما کلید سرویس هوش مصنوعی و آدرس واسط را ندارد.
- برای بازیابی همان صفحه را باز کن و فایل را انتخاب کن. اول محتوای فایل بررسی و نمایش داده می‌شود و تا خودت تأیید نکنی چیزی جایگزین نمی‌شود. به‌طور پیش‌فرض قبل از بازیابی از داده‌های فعلی هم پشتیبان گرفته می‌شود.

## تنظیم هوش مصنوعی (اختیاری)

1. در [console.anthropic.com](https://console.anthropic.com) یک کلید API بساز و برایش سقف هزینهٔ ماهانه بگذار.
2. در اپ: تنظیمات ← تنظیم کلید سرویس AI ← کلید را وارد کن و ذخیره بزن.
3. مدل پیش‌فرض `claude-opus-5-5` است و از همان صفحه قابل تغییر است.

کلید رمزنگاری‌شده فقط روی گوشی می‌ماند. عکس‌ها و اطلاعات فقط وقتی فرستاده می‌شوند که خودت شناسایی یا یکی از قابلیت‌های همراه را شروع کنی. ارسال یادداشت‌ها و برداشت‌ها را می‌توانی در تنظیمات خاموش کنی.

قابلیت‌های هوش مصنوعی:
- شناسایی کتاب از عکس جلد یا شناسنامه، و شناسایی بازی اصلی از عکس جعبه؛ پیشنهادها قبل از اعمال فیلد به فیلد قابل بررسی‌اند.
- همراه مطالعه: سؤال برای ثبت برداشت، ایدهٔ خلاقانه، و ارتباط با کتاب‌های دیگر.
- توضیح انتخاب بازی برای جمع، برداشت از آمار، و پیشنهاد برای فهرست علاقه‌مندی.

پاسخ‌های قبلی ذخیره می‌شوند و آفلاین هم قابل مشاهده‌اند.

## اتصال BoardGameGeek (اختیاری)

BGG از سال ۲۰۲۵ برای استفاده از API خود ثبت برنامه و توکن شخصی می‌خواهد:

1. در [boardgamegeek.com/applications](https://boardgamegeek.com/applications) با حساب خودت یک برنامهٔ غیرتجاری (non-commercial) بساز.
2. تأیید BGG ممکن است تا یک هفته طول بکشد. بعد از تأیید، در بخش Tokens یک توکن بساز.
3. در اپ: تنظیمات ← اتصال BoardGameGeek ← توکن را وارد کن و «آزمایش اتصال» را بزن.

بعد از آن، در صفحهٔ بازی (منو یا «مشخصات فنی») گزینهٔ «پیدا کردن این بازی در BGG» را بزن. بازی اصلی را انتخاب کن و تعداد بازیکن مجاز، زمان، پیچیدگی (وزن BGG)، تعداد پیشنهادی جامعه و سبک را فیلد به فیلد تأیید کن. مقدارهایی که خودت دستی وارد کرده‌ای به‌طور پیش‌فرض دست نمی‌خورند. عکس نسخهٔ خودت فقط وقتی عوض می‌شود که گزینهٔ «تصویر باکیفیت جعبه از BGG» را تیک بزنی. توکن مثل کلید هوش مصنوعی رمزنگاری‌شده فقط روی گوشی می‌ماند و درخواست‌ها مستقیم از گوشی به BGG می‌روند.

## جلد باکیفیت

روی جلد کتاب یا بازی بزن (یا از منو «جلد باکیفیت» را انتخاب کن). سه راه هست:

- **اسکن با دوربین:** از جلد نسخهٔ خودت عکس بگیر. هوشواره (اگر تنظیم شده) چهار گوشهٔ جلد را پیدا می‌کند و تو می‌توانی جابه‌جایشان کنی؛ بعد کجی صاف می‌شود و نور و رنگ اصلاح می‌شود. صاف کردن و اصلاح روی خود گوشی انجام می‌شود؛ برای پیدا کردن گوشه‌ها فقط یک نسخهٔ کوچک‌شده از عکس فرستاده می‌شود. بدون هوشواره هم گوشه‌ها را دستی می‌گذاری.
- **لینک طاقچه (کتاب):** برای کتاب‌های دیجیتال، لینک کتاب را از اپ یا سایت طاقچه کپی کن و در همین صفحه بچسبان؛ جلد اصلی ناشر (حدود ۸۰۰×۱۱۷۰ پیکسل) دریافت می‌شود. این تصویر هم مثل تصویر BGG از طریق wsrv.nl دریافت می‌شود.
- **تصویر جعبه از BGG (فقط بازی):** تصویر اصلی جعبهٔ بازی‌ای که به BGG وصل است. تصویر از طریق wsrv.nl (یک سرویس عمومی کش تصویر) دریافت می‌شود، چون BGG اجازهٔ خواندن مستقیم تصویر را به وب‌اپ نمی‌دهد؛ فقط آدرس تصویر به آن فرستاده می‌شود.
- **ChatGPT:** متن درخواست آماده (مشخصات کتاب یا بازی و استاندارد تصویر اپ) کپی و ChatGPT باز می‌شود. تصویر ساخته‌شده را ذخیره کن و از همان صفحه انتخابش کن.

جلد تازه اولین عکس می‌شود و عکس‌های قبلی پاک نمی‌شوند.

## چرا آدرس جداگانه؟

درنگ روی آدرس مخصوص خودش (`derang-app.github.io`) است. اگر دو اپ نصب‌شدنی روی یک آدرس github.io باشند، Chrome اندروید هنگام باز کردن اپ دوم خطای «Could not open app» می‌دهد.

## توسعه

```bash
npm install
npm run dev      # سرور توسعه
npm test         # تست‌ها
npm run build    # خروجی نهایی در dist/
```

ساختار: `src/db` (مدل داده و Dexie)، `src/lib` (منطق انتخاب بازی، پشتیبان، تاریخ شمسی، جست‌وجوی فارسی)، `src/ai` (لایهٔ قابل‌تعویض هوش مصنوعی)، `src/screens` و `src/ui` (رابط).
مرجع طراحی: بستهٔ UX Pilot، نسخه‌های انتهایی هر صفحه.
